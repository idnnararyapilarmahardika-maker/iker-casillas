# 🧤 Iker Casillas Tribute & Save Simulator

Website tribute interaktif untuk legenda kiper Real Madrid, **Iker Casillas**. Dilengkapi dengan mini-game *Save Simulator* yang menantang refleks, timeline karir lengkap dari La Fábrica hingga pensiun, serta tampilan modern dengan dukungan *Dark Mode*.

🔗 **Live Demo:(https://iker-casillas.vercel.app)

## ✨ Fitur Utama

-   **🧤 Save Simulator Interaktif**: Uji refleksmu sebagai kiper! Klik bola yang datang dengan kecepatan bervariasi untuk melakukan penyelamatan. Sistem skor dan statistik save ratio tersimpan secara real-time.
-   **📜 Timeline Karir Lengkap**: Penjabaran detail perjalanan karir Iker Casillas mulai dari akademi Real Madrid, masa kejayaan di Santiago Bernabéu, hingga penghormatan terakhir saat pensiun.
-   **🌙 Dark Mode Toggle**: Antarmuka yang nyaman di mata dengan opsi tema gelap/terang yang dapat beralih mulus sesuai preferensi pengguna.
-   **📱 Fully Responsive**: Tampilan optimal di berbagai perangkat, mulai dari laptop Lenovo IdeaPad Slim 1 hingga smartphone.

## 🛠️ Tech Stack

Proyek ini dibangun menggunakan teknologi web standar tanpa framework eksternal untuk memaksimalkan pemahaman fundamental:

-   **HTML5**: Struktur semantik dan aksesibilitas
-   **CSS3**: Custom Properties (Variables), Flexbox, Grid Layout, dan Transitions
-   **Vanilla JavaScript (ES6+)**: DOM Manipulation, Event Handling, LocalStorage untuk persistensi skor game
-   **Vercel**: Platform deployment dengan CI/CD otomatis

## 🎮 Cara Bermain Save Simulator

1.  Buka halaman utama dan cari section "Save Simulator"
2.  Klik tombol **"Start Game"** untuk memulai
3.  Bola akan muncul secara acak dengan kecepatan yang meningkat seiring waktu
4.  **Klik bola secepat mungkin** sebelum melewati garis gawang
5.  Skor dan persentase penyelamatan akan tercatat otomatis
6.  Tekan **"Reset"** untuk mengulang permainan

## 🚀 Deployment

Website ini di-hosting di **Vercel** dengan integrasi GitHub otomatis. Setiap push ke branch `main` akan memicu deployment baru secara instan.
